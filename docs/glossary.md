# Glossary — discussion words and the identifiers behind them

Where the word used in conversation, docs, or the clients differs from the names in the
code, the pair is listed here. A rename that closes a gap removes its row. Words with more
than one current meaning are listed with each sense, so a reader can tell which is meant.

| word | identifiers | governing doc |
| --- | --- | --- |
| **triage primer** — a capped request that plants the triage model's cache | `Triager::prime`, `RequestOrigin::TriagePrimer` | transport.md |
| **stored request** (triage keepalive) — what the triage lineage's keepalive re-sends: the last primer, or the last result triage's request ending at its last breakpoint (its cache point) | `api::SentRequest`, `SentRequest::through_last_breakpoint`, `triage::SentTriage`, `Session::store_triage_request`, `daemon::keepalive::StoredRequest` | transport.md |
| **text view** — what a separate triage model reads: the history (head summaries, the digest up to the view cut, the triaged tail), then the current step and the ask | `TriageView::Text`, `Triager::view`, `src/triage/text_view.rs`, `efference dev triage --view text` | triage.md |
| **triaged tail** — the text view's recent steps in full, each result as the agent read it; not a triage request's throwaway tail | `TRIAGED_TAIL_HIGH_WATER`, `TRIAGED_TAIL_LOW_WATER`, `digest::Options::verbatim` | triage.md |
| **cut** (1), compaction cut — where a compaction's account ends, the record after it staying verbatim | `digest::CUT`, `digest::Options::cut`, `compaction_cut` | summary.md |
| **cut** (2), view cut — where the text view's digest ends and its triaged tail begins | `TextViewLayout::cuts`, `text_view::history` | triage.md |
| **summary** — the text that replaces a range of the transcript, and the log entry that carries it | `Payload::Summary(Summary { from, upto, text, made_by, audience })` | summary.md |
| **consolidation** — the agent replaces a region of its own transcript with a summary, having seen that region in full | the `consolidate` tool, `MadeBy::Consolidation`, `RequestOrigin::Consolidation` | consolidate.md |
| **compaction** — the harness writes a summary from the digest, without the full transcript | `MadeBy::Compaction`, `src/compact.rs` (`compact::summarize`), `src/daemon/compact.rs`, `POST /loop/compact`, `current_operations.compaction` and the `compaction_failure` state topic, `efference dev compact`, `RequestOrigin::Compaction` | summary.md |
| **reasoning summary** — a provider's account of its own reasoning (OpenAI's term); not a *summary* in the sense above | `ResponsesReasoningSummary`, `WireSummaryPart` | transport.md |
| **session listing** — one row per hosted session in `GET /sessions` | `ListedSession`, `ListingEvent`, `Host::listing`, `src/daemon/host/listing.rs` | control-api.md |
| **gate** — a tool call held for a permission decision | `Approval`, `/state`'s `gate`, the `gated` loop phase | permissions.md |
| **gate grant** — the one config change a gate offers to commit, chosen from why the call held; not a *proposal*, which is a `Proposed` config edit queued for an orchestrator | `policy::GateGrant`, `policy::gate_grant`, `Session::gate_grant`, `/state`'s `gate.grant` | permissions.md |
| **gate decision**, **decider** — the record of one accepted decision on a held call, and who made it | `Telemetry::GateDecision` (`GateDecision { call_id, decision, source, note_submission }`), `telemetry.gate_decision`, `PUT /approvals/:call_id`'s `source` | control-api.md |
| **escalate**, **escalation** — passing a held call's decision up the supervisor chain without deciding it; the call stays held. The only sense of the word | `decide` with `escalate` (`control_tools::Decision::Escalate`), `Session::escalate`, `Telemetry::Escalation`, `telemetry.escalation`, `/state`'s `gate.escalations`, `POST /approvals/:call_id/escalate` | permissions.md |
| **grain** — which render a transcript read answers with: the conversation (the default) or the entry-by-entry audit | `daemon::transcript::Grain`, `GET /transcript?grain=audit`, `client::TranscriptRead::audit` | control-api.md |
| **zoom** (1) — a transcript read of one entry or call in full; agents are told "read one entry in full", never "zoom" | `GET /transcript?seq=8.2`, `daemon::transcript::zoom`, `transcript::Handle` | control-api.md |
| **zoom** (2) — the web client's image viewer scaling and panning an image | `web/src/ui/zoom.ts` | web-client.md |
| **loop phase** — where the loop is, as one exclusive value | `LoopPhase`, `BlockedReason`, the `loop_phase` state topic, `Session::loop_phase`, `src/daemon/phase.rs` | control-api.md |
| **verb** (loop verb) — an action a client offers on a loop route; whether each route would accept it now is published | the `verbs` state topic, `Session::continue_verdict`, `Session::compaction_verdict`, `Session::turn_delivery`, the TUI's strip and keys | control-api.md, tui.md |
| **process monitor** — background-process supervision: spawning, tails, exit notifications, `wait`, `read_process`, `kill_process` | `ProcessMonitor`, `src/process_monitor.rs`, `/processes` | process-monitor.md |
| **upstream** — the model API endpoint | `--upstream`, `api::Upstream`, `upstream_failure`, `upstream_retry` | transport.md |
| **agent** — another session, as the session-control verbs name it to a model; each agent is a session on the host, its id naming both | the `agents__` namespace (`control_tools::NAMESPACE`), every verb's `agent` argument, a turn's `<id> (agent):` prefix (`frontend::wire_label`) | tools.md |
| **driver**, **drives** — a session or client whose `message` to a session is its next user message and whose `interrupt` and `archive` reach it: its creator chain, its supervisor, its successor, or any operator client | `HostExecutor::drives`, `Relation::Driver` | tools.md |
| **read cursor** — the last seq a reader was shown of a session's transcript, which a default `transcript` read continues from | `Hosted::read_cursors`, `ClientExecutor::cursor`, `daemon::transcript::cursor::ReadPlan` | tools.md |
| **supervisor** — the session that reviews this one's gates, the one session that may decide them wherever they are routed, and a driver of it; by default the creating session, settable after creation | `HostExecutor::supervises`, `Relation::MayDecide`, `ReviewLevel::Supervisor`, `resolved_review_level: "supervisor"`, `/state`'s `supervisor`, `Session::supervisor`, `Hosted::supervisor` (the pointer), `Host::set_supervisor`, `PATCH /sessions/:id {"supervisor"}`, the `supervisor` control verb, `telemetry.supervisor_set` | permissions.md |
| **follow** — hold a session's status stream open, which wakes the follower on each status; it confers no authority and is not supervising | `status(follow: true)`, the `follow:` URL (`control_tools::follow`) | operating.md |
| **enrolled device** — a row in the `devices` table: the holder of one TCP credential, a browser that signed in or a script given a token; revoked by deleting the row. Socket clients are not devices | `devices::Device`, `devices::Store`, `devices::DeviceId`, `devices::Kind`, `devices::Joined`, `efference devices`, `GET`/`POST /auth/devices`, `DELETE /auth/devices/:id` | web-bind.md |
| **device token** — the TCP credential naming one enrolled device, `efference_` + base64url(id ‖ HMAC tag), derived from the root and never stored; the web client holds its own as its *bearer* | `auth::DeviceTokens`, `Root::device_tokens`, `auth::DEVICE_TOKEN_PREFIX`, `TcpAuth::enroll`, `devices::Enrolled`, `web/src/api/bearer.ts` | web-bind.md |
| **device** (push) — a push subscription, named by its endpoint's host and a hash of the endpoint; not an enrolled device, and a browser can be both | `push::device_label`, `DeviceDelivery { host, device }`, `telemetry.push` `delivery {devices}` | web-push.md |
| **pending sign-in** — a browser waiting to collect a device token: a `/pair` request the operator approves by its short code, or a sign-in link approved in advance; lives 90 s and is claimed once. Never called a *pairing*, the word for a tool_use and its tool_result; the route is `/pair` | `sign_ins::Store`, `sign_ins::Pending`, `sign_ins::Claim`, the `pending_sign_ins` table, `POST /pair`, `GET /auth/pending`, `POST /auth/approve`, `GET /auth/link`, `efference devices approve`, `devices::Joined::Code`/`Link` | web-bind.md |
| **short code** — what the operator reads off the new browser and types at the host, `KQ7-M4X`; names a pending sign-in and authorizes nothing | `sign_ins::ShortCode`, `/pair`'s `code`, `POST /auth/approve`'s `code` | web-bind.md |
| **claim secret** — the 128-bit value that collects a device token once: held by the page that asked, or carried in a sign-in link's `#claim=` fragment; stored only as its SHA-256 | `sign_ins::ClaimSecret`, `/pair`'s `claim`, `POST /pair/claim`, `web/src/ui/bootClaim.ts` | web-bind.md |
| **fork**, **branch** — *reserved* for a future session concept (a new variant of an existing session); not to be used for anything else | `TitlePeek`, `ForkSpot` still use *fork*/*peek* for side requests | |
